SQL basics8 topics

Data types

The type you choose decides what a column can hold and how much space it takes.

Type Holds Example
INT Whole numbers 42
DECIMAL(m, n) Exact decimals: m digits in total, n of them after the point DECIMAL(6,2) holds 1234.56
VARCHAR(x) Text up to x characters VARCHAR(50)
BLOB Binary data (images, files)
DATE A date, YYYY-MM-DD 2024-03-15
TIMESTAMP Date and time, YYYY-MM-DD HH:MM:SS 2024-03-15 09:30:00

Use DECIMAL for money, never FLOAT: floats round, decimals don't.

Tracing a query by hand

When a query confuses you, run it in your head on a tiny table. Two steps.

1. Know the tables

  • Columns and types: the names and types (text, number, date) of every column involved.
  • Sample data: picture or sketch three or four rows.

2. Follow the order SQL really runs in

You write SELECT first, but the database runs it almost last:

How each join behaves:

  • INNER JOIN keeps only rows that match in both tables.
  • LEFT / RIGHT JOIN keeps every row of one side and fills missing matches with NULL.
  • FULL JOIN keeps every row of both sides.

Example

SELECT department, COUNT(employee_id) AS employee_count
FROM employees
GROUP BY department
ORDER BY employee_count DESC;
  1. Picture a small employees table.
  2. GROUP BY: make one pile per department: Sales, Marketing...
  3. SELECT and COUNT: count the rows in each pile.
  4. ORDER BY: put the biggest pile first. This only changes how the result is shown.

SQL commands

SQL is split into smaller languages by job:

DDL Data Definition · DML Data Manipulation · DQL Data Query · DCL Data Control · TCL Transaction Control

CREATE

CREATE DATABASE shop;

CREATE TABLE employees (
  id      INT NOT NULL AUTO_INCREMENT,
  name    VARCHAR(50) NOT NULL,
  phone   VARCHAR(20) UNIQUE,
  dept_id INT NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (dept_id) REFERENCES departments(id)
);

Constraints you can put on a column:

Constraint Meaning
NOT NULL The column must have a value
UNIQUE No two rows may share a value
DEFAULT x Use x when no value is given
CHECK (cond) Every value must pass the condition
PRIMARY KEY Unique and not null: the row's identity
FOREIGN KEY ... REFERENCES Must match a key in another table
AUTO_INCREMENT MySQL numbers new rows for you
INDEX Faster lookups on this column

ALTER, DROP and TRUNCATE

ALTER TABLE employees ADD (email VARCHAR(100));   -- add a column
ALTER TABLE employees MODIFY phone VARCHAR(30);   -- change a column's type
ALTER TABLE employees DROP COLUMN email;          -- remove a column

TRUNCATE TABLE employees;   -- empty the table, keep its structure
DROP TABLE employees;       -- delete the table itself
DROP DATABASE shop;         -- delete the whole database

INSERT, UPDATE and DELETE

INSERT INTO employees VALUES (1, 'Rafi', '017...', 2);          -- every column, in order
INSERT INTO employees (name, dept_id) VALUES ('Nila', 1), ('Tamim', 2);

UPDATE employees SET phone = '018...' WHERE id = 1;

DELETE FROM employees WHERE id = 3;   -- the matching rows
DELETE FROM employees;                -- every row

Always write the WHERE before running an UPDATE or DELETE. Without it, every row changes.

Access and transactions

GRANT SELECT, INSERT ON shop.* TO 'app'@'localhost';
REVOKE INSERT ON shop.* FROM 'app'@'localhost';

START TRANSACTION;
UPDATE accounts SET balance = balance - 100 WHERE id = 1;
SAVEPOINT after_debit;
UPDATE accounts SET balance = balance + 100 WHERE id = 2;
COMMIT;      -- keep both changes (ROLLBACK would undo them)

Arithmetic and comparison

Kind Operators
Arithmetic + - * / % (remainder)
Comparison = > >= < <=
Not equal <> or != 
SELECT name, salary * 12 AS yearly FROM employees WHERE salary >= 50000;

Filtering with WHERE

AND, OR, NOT

SELECT * FROM employees WHERE dept = 'CSE' AND salary > 50000;   -- both true
SELECT * FROM employees WHERE dept = 'CSE' OR dept = 'EEE';      -- at least one true
SELECT * FROM employees WHERE NOT (dept = 'CSE');                -- everyone except CSE

BETWEEN

A shorter way to write a range. It includes both ends.

SELECT * FROM employees WHERE salary BETWEEN 50 AND 100;   -- same as salary >= 50 AND salary <= 100

IN

A shorter way to write many ORs. NOT IN gives the opposite.

SELECT * FROM employees WHERE dept IN ('CSE', 'EEE', 'ME');

LIKE

Finds a text pattern.

Wildcard Matches Example
% any number of characters 'M%': starts with M
_ exactly one character '_a%': second letter is a 
SELECT * FROM employees WHERE first_name LIKE 'M%';

In MySQL, LIKE ignores case with the usual settings. ILIKE (case-insensitive LIKE) exists in PostgreSQL, not MySQL.

ALL and ANY

Compare a value with every row a subquery returns.

SELECT s1 FROM t1 WHERE s1 > ALL (SELECT s1 FROM t2);   -- bigger than every value
SELECT s1 FROM t1 WHERE s1 > ANY (SELECT s1 FROM t2);   -- bigger than at least one

EXISTS

True when the subquery returns any row at all.

SELECT name FROM customers c
WHERE EXISTS (SELECT 1 FROM orders o WHERE o.cus_id = c.cus_id);

LIMIT

Shows only some of the rows.

SELECT * FROM employees LIMIT 5;      -- first 5 rows
SELECT * FROM employees LIMIT 5, 2;   -- skip 5, then show 2 (rows 6 and 7)

CASE and IF

CASE

SQL's if / else-if / else. The first WHEN that is true wins.

SELECT name,
  CASE
    WHEN salary >= 100000 THEN 'High'
    WHEN salary >= 50000  THEN 'Medium'
    ELSE 'Low'
  END AS band
FROM employees;

CASE works inside ORDER BY too.

IF

A one-line choice between two values.

SELECT name, IF(salary > 50000, 'Yes', 'No') AS well_paid
FROM employees;

Handling NULL

COALESCE

Returns the first value that is not NULL. Good for defaults.

SELECT COALESCE(email, 'email not found') FROM user_data;

Safe division with NULLIF

NULLIF(a, b) returns NULL when a = b, otherwise a. Dividing by NULL gives NULL instead of an error, so this avoids divide-by-zero:

SELECT COALESCE(10 / NULLIF(0, 0), 0);   -- 0, not an error

Text functions

Function Does Example → result
TRIM(s) Removes spaces at both ends (LTRIM / RTRIM: one end) TRIM(' hi ') → 'hi'
REPLACE(s, from, to) Replaces every from with to REPLACE('a-b', '-', '+') → 'a+b'
SUBSTRING(s, start, length) Part of the text SUBSTRING('MySQL', 3, 3) → 'SQL'
CONCAT(a, b, ...) Joins texts CONCAT('My', 'SQL') → 'MySQL'

Positions in SQL start at 1, not 0.

SELECT REPLACE(department, 'communications', 'NV') AS dept FROM team;
Querying6 topics

GROUP BY, HAVING, ORDER BY and window functions

GROUP BY

Puts rows with the same value in one group, usually so you can count or add them up per group: "how many customers in each country?"

SELECT country, COUNT(*) AS customers
FROM customers
GROUP BY country;

HAVING

WHERE filters rows before grouping and can't use aggregates. HAVING filters groups after.

SELECT country, COUNT(*) AS customers
FROM customers
WHERE active = 1
GROUP BY country
HAVING COUNT(*) > 10
ORDER BY customers DESC;

ORDER BY

Sorts the result: ASC (the default) or DESC.

SELECT name, country FROM employees ORDER BY salary DESC;

MySQL lets you sort by a column you didn't select (like salary above). Some other databases don't.

Window functions: OVER()

An aggregate squashes many rows into one. A window function works out the same kind of value but keeps every row, adding the result as a new column.

SELECT region, sales_amount,
       SUM(sales_amount) OVER (PARTITION BY region) AS regional_total
FROM sales;
  • OVER() turns a function into a window function.
  • PARTITION BY is like GROUP BY, but every row stays.
  • ORDER BY inside OVER() sets the order within each partition.

Ranking functions, on this table:

name value RANK() DENSE_RANK() ROW_NUMBER()
east 100 1 1 1
west 100 1 1 2
north 101 3 2 3
south 102 4 3 4 
SELECT name, value,
       RANK()       OVER (ORDER BY value) AS rnk,
       DENSE_RANK() OVER (ORDER BY value) AS dense,
       ROW_NUMBER() OVER (ORDER BY value) AS row_no
FROM t;
  • RANK(): ties share a rank and the next rank is skipped (1, 1, 3).
  • DENSE_RANK(): ties share a rank, nothing is skipped (1, 1, 2).
  • ROW_NUMBER(): every row gets its own number.

Analytic functions: LAG() and LEAD() read the previous or next row; NTILE(n) splits the rows into n buckets.

Aggregate functions

Each one turns many rows into one value.

Function Returns
COUNT(col) How many values (not NULL); COUNT(*) counts rows
SUM(col) The total
AVG(col) The average
MIN(col) / MAX(col) The smallest / largest 
SELECT COUNT(*), AVG(salary), MAX(salary) FROM employees;

Joins

Every example uses these two tables:

customerorders
cus_idnamecus_iditem
1hamim1Pizza
2rabbi1Shake
4Chicken
SELECT c.name, o.item
FROM customer c
INNER JOIN orders o ON c.cus_id = o.cus_id;   -- swap INNER for LEFT or RIGHT
Join Keeps Result
INNER JOIN Only rows that match on both sides hamim–Pizza, hamim–Shake
LEFT JOIN Every customer; no order → NULL ...plus rabbi–NULL
RIGHT JOIN Every order; no customer → NULL ...plus NULL–Chicken
FULL JOIN Everything from both sides all of the above

MySQL has no FULL JOIN. Get the same result with a LEFT JOIN UNION a RIGHT JOIN.

The NULL–Chicken row is right for a right join, but in a real database an order for customer 4 who doesn't exist should be blocked by a foreign key.

Self join and cross join

  • Self join: a table joined with itself, e.g. each employee next to their manager.
    SELECT e.name, m.name AS manager
FROM employees e LEFT JOIN employees m ON e.manager_id = m.id;
  • Cross join: every row of one table with every row of the other (3 × 4 = 12 rows).

UNION and set operations

UNION stacks the results of two SELECTs. Both must have the same number of columns with matching types.

SELECT customer_id, name, region FROM customers_region1
UNION
SELECT customer_id, name, region FROM customers_region2;
region1 region2 UNION UNION ALL
1 Alice East 2 Bob West 1 Alice East 1 Alice East
2 Bob West 3 Charlie North 2 Bob West 2 Bob West
3 Charlie North 2 Bob West
3 Charlie North
  • UNION removes duplicates (Bob appears once).
  • UNION ALL keeps them all, and is faster.
  • INTERSECT keeps rows found in both; EXCEPT (called MINUS in Oracle) keeps rows of the first not in the second. MySQL has both since version 8.0.31.

Common table expressions (CTE)

A CTE is a named subquery written at the top of a query with WITH. It exists only while that query runs, and it makes long queries read top to bottom.

WITH cte_name (col1, col2) AS (
  SELECT ...
)
SELECT * FROM cte_name;
  • Listing the column names (col1, col2) is optional, but good practice.
  • Without the list, the CTE takes the names of the columns its query selects.

Example

Find the sales that are above their region's average:

WITH regional_averages AS (
  SELECT region, AVG(sales_amount) AS avg_sales
  FROM sales_data
  GROUP BY region
)
SELECT s.region, s.sales_amount
FROM sales_data s
JOIN regional_averages ra ON s.region = ra.region
WHERE s.sales_amount > ra.avg_sales;

Recursive CTE

A CTE that refers to itself, for trees and hierarchies (org charts, categories):

WITH RECURSIVE nums (n) AS (
  SELECT 1
  UNION ALL
  SELECT n + 1 FROM nums WHERE n < 5
)
SELECT n FROM nums;   -- 1, 2, 3, 4, 5

Temporary tables

A temporary table works like a normal table but lives only for your session. It disappears when you disconnect, and other sessions can't see it.

CREATE TEMPORARY TABLE high_value_orders (
  order_id     INT,
  customer_id  INT,
  order_amount DECIMAL(10,2)
);

INSERT INTO high_value_orders
SELECT order_id, customer_id, total_amount
FROM sales
WHERE total_amount > 1000;

The #local and ##global temp tables you may see online are SQL Server syntax. In MySQL it's CREATE TEMPORARY TABLE, and there are no global temp tables.
