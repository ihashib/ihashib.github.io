Installation and first project
  • Link: https://learnesp32.com/videos/1/1_%5Bwindows%5D%20installing%20the%20esp-idf
  • Download
    • Ubuntu 20.04
      • In VS Code extensions, search Espressif IDF
      • Install and then open the extension.
      • Select express install and follow the installation procedure.
    • Windows
      • Go to https://docs.espressif.com/projects/esp-idf/en/latest/esp32/get-started/index.html#step-2-get-esp-idf
      • Scroll down to find “Manual Installation”
      • Select Windows Installer
      • In the next page, click on the Windows Installer Download under ESP-IDF Tools installer
      • In the next page select Universal Online Installer
      • ESP IDF setup
    • Open the Universal Online installer exe file
    • Select English > ok
    • In the next window it will scan your system, if Apply Fixes button is available, then press on it, otherwise click next
    • Download ESP-IDF > Next
    • Select v4.4(release version) > Next
    • Go to the C drive, open a new folder esp
    • Inside ESP IDF folder, create 2 more folders, idf and Tools
    • Back to the installer, Select Full installation > Next > Install
    • NOTE: The folder names must not contain spaces.
    • VS Code config
    • Open VScode > Extensions > Search ESP IDF > Install
    • Press F1,
    • If there’s Use Existing Setup, click on that. If not then, press Express.
    • After configuration is done, close the window.
    • Again, F1 > ESP IDF New Project
      • Give the project name, MUST NOT HAVE SPACE.
      • Choose ESP-IDF Board
      • Custom board > ESP32 Module > Choose template
      • Choose ESP-IDF in the drop down > sample_project
      • Clock on sample project > Create project using template sample project
      • A popup will appear, clock Yes
      • A new VSCode environment will appear
      • Select [Scan for kits] , if the following window appears
      • Alternatively, click on No kit selected
      • Select main > main.c
      • To enhance intellisense, .vscode > Settings.json
        • "C_Cpp.intelliSenseEngine": "Default",

Bluetooth BLE
  • GAP
  • AP is an acronym for the Generic Access Profile, and it controls
connections and advertising in Bluetooth. GAP is what makes your
device visible to the outside world, and determines how two devices
can (or can't) interact with each other.
  • GATT
  • Application Example
  • Check bluetooth folder in ESP-IDF examples, which contains the following demos and their tutorials:
  • This is a GATT server demo and its tutorial. This demo creates a GATT service with an attribute table,
  • About GATT
  • https://www.oreilly.com/library/view/getting-started-with/9781491900550/ch04.html
  • GATT makes it possible for ble devices to connect and transfer user profiles and data over ble.
  • GATT also provides a reference profile framework that everyone needs to follow and this enables communication between devices from different vendors.
  • GATT uses Attribute protocol (ATT) for transport protocol. ATT organizes data hierarchically, so similar data is called characteristics and a group of similar characteristic data is called services.
  • GATT attributes are only given by the server. It contains config data about the services and characteristics. Attributes contain data about itself then the actual data.
  • They are addressable pieces of information that can contain relevant user data (or metadata) about the structure and grouping of the different attributes contained within the server.
  • which releases the user from adding attributes one by one. This is the recommended method of adding attributes.
