Getting started1 topic

Setting up

What you need:

  • A code editor: VS Code.
  • Git and a GitHub account, to save and share your work.
  • Live Server, a VS Code extension that reloads the page in the browser every time you save. The easiest option.

Prefer the terminal? browser-sync does the same:

npm install -g browser-sync          # needs Node.js; on Linux you may need sudo
browser-sync start --server --files "*"

--server serves the current folder and --files "*" reloads the page when any file changes.

Fonts: pick one on Google Fonts, then copy its <link> into your HTML and its font-family into your CSS.

Try code online: CodePen, JSFiddle. Learn more: CSS-Tricks.

HTML 518 topics

HTML5 overview

HTML (HyperText Markup Language) describes what is on a page: headings, paragraphs, links, images. CSS then decides how it looks.

HTML keeps growing (the WHATWG maintains it as a "living standard"), so these help:

Site Use it to
caniuse.com Check which browsers support a feature
validator.w3.org Find mistakes in your HTML
MDN Web Docs Look up any tag or property

Basic structure of a page

Every page has the same skeleton:

<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <title>Hello!</title>
  </head>
  <body>
    <!-- everything you see goes here -->
    This is the body.
  </body>
</html>
  • <head> holds information about the page (title, styles, meta tags).
  • <body> holds what is shown.
  • <!-- ... --> is a comment: the browser ignores it.

Block and inline elements

Block Inline
<div>, <p>, <h1>–<h6>, <form>, <ul> <span>, <a>, <img>, <strong>, <em>
Starts on a new line Stays in the line
Takes the full width Only as wide as its content
  • Put inline elements inside block elements, not the other way round.
  • A well-written <h1> matters a lot for search engines (SEO).

HTML5 semantic tags

Semantic tags name the part of the page they hold, instead of a meaningless <div>.

Tag Holds
<header> Logo, title, top links
<nav> The main navigation links
<main> The page's main content (one per page)
<section> A themed part of the page
<article> Something that stands on its own: a post, a card
<aside> Side content: a sidebar, related links
<footer> Copyright, privacy policy, contact
<details> A box the reader can open and close 
<header>
  <div class="container">
    <h1 id="branding">My site</h1>
    <nav>
      <ul><li><a href="#">Home</a></li></ul>
    </nav>
  </div>
</header>

<section class="boxes">
  <div class="container">
    <div class="box"><img src="a.png" alt=""><p>...</p></div>
    <div class="box"><img src="b.png" alt=""><p>...</p></div>
  </div>
</section>

<footer><p>&copy; 2024</p></footer>

Meta tags

Meta tags sit in <head> and tell browsers and search engines about the page.

<meta charset="utf-8">                                     <!-- text encoding -->
<meta name="viewport" content="width=device-width, initial-scale=1">   <!-- needed for phones -->
<meta name="description" content="Blog by Hasib">          <!-- shown in search results -->

Without the viewport tag, phones show the desktop layout zoomed out.

Headings

Six levels, from <h1> (most important) to <h6>.

<h1>Page title</h1>
<h2>Section</h2>
<h3>Sub-section</h3>

Use one <h1> per page and don't skip levels. Search engines and screen readers use headings to understand the page.

Paragraphs

<p> is a block element for a paragraph of text.

<p>This is a paragraph.</p>

Bold and italic

<strong>Important</strong>   <!-- bold, and means "this matters" -->
<em>Emphasis</em>            <!-- italic, and means "stress this" -->

Lists

Lists are used for content and also for navigation menus.

<ol>                <!-- ordered: 1, 2, 3 -->
  <li>First</li>
  <li>Second</li>
</ol>

<ul>                <!-- unordered: bullets -->
  <li>Apples</li>
  <li>Pears</li>
</ul>

Tables

<table>
  <thead>              <!-- the column names -->
    <tr>               <!-- a row -->
      <th>Name</th>    <!-- a header cell -->
      <th>Age</th>
    </tr>
  </thead>
  <tbody>              <!-- the data -->
    <tr>
      <td>Rafi</td>    <!-- a data cell -->
      <td>24</td>
    </tr>
  </tbody>
</table>

Forms

A form collects input and sends it to the server.

<form action="process.php" method="POST">
  <label for="first">First name</label>
  <input id="first" type="text" name="first_name" placeholder="Enter first name">

  <textarea name="message"></textarea>

  <select name="gender">
    <option value="male">Male</option>
    <option value="female">Female</option>
  </select>

  <input type="number" name="age" value="30">
  <input type="submit" value="Send">
</form>
Attribute Meaning
action Where the data is sent
method GET (data in the URL) or POST (data in the request body)
name The key the value is sent under
placeholder Grey hint text that disappears when typing
value A starting value

Common types: text, email, password, number, date, checkbox, radio, submit.

Buttons

<button type="button" onclick="sayHi()">Click me</button>

A button does nothing by itself; JavaScript gives it a job.

Quotes, abbreviations and citations

<blockquote cite="https://example.com">A long quote, shown indented.</blockquote>
<p>The <abbr title="World Wide Web">WWW</abbr> is awesome.</p>   <!-- hover shows the full name -->
<p><cite>HTML is Cool</cite> by me</p>                            <!-- title of a work -->

Special characters

Some characters mean something in HTML, so you write them as entities:

Write To show
&lt; <
&gt; >
&amp; &
&quot; "
&copy; ©
&nbsp; a space that never breaks the line

Links

<a href="about.html">About</a>                              <!-- a page in the same folder -->
<a href="https://example.com" target="_blank">Example</a>   <!-- opens in a new tab -->

<a> is inline, but it may wrap block content (a whole card, for example).

Linking to part of a page

Give the target an id, then link to # plus that id:

<section id="contact">...</section>

<a href="#contact">Go to contact</a>

Images

<img src="images/photo.jpg" width="300" height="255" alt="A red bicycle">
  • alt describes the image for screen readers, and shows if the image fails to load.
  • Setting width and height stops the page jumping while the image loads.
  • An image can be a link: wrap it in <a href="...">...</a>.

Video

A video file of your own:

<video width="640" controls>
  <source src="clip.mp4" type="video/mp4">
</video>

controls shows play, pause and the seek bar. autoplay starts it by itself (most browsers require muted too).

From YouTube: Share → Embed, then paste the <iframe>:

<iframe width="560" height="315" src="https://www.youtube.com/embed/VIDEO_ID" allowfullscreen></iframe>

CSS overview

CSS (Cascading Style Sheets) decides how HTML looks. A rule picks elements with a selector, then sets properties:

p {               /* selector: every <p> */
  color: blue;    /* declaration: property: value; */
}

Selectors: element, class and id

p      { color: blue; }    /* every <p> */
.note  { color: blue; }    /* every element with class="note" */
#title { color: blue; }    /* the one element with id="title" */
div, .note { color: blue; }  /* several selectors at once */

<p class="note">Uses the .note rule</p>
<h1 id="title">Uses the #title rule</h1>

An id must be unique on the page; a class can be used any number of times.

Combining selectors

Selector Picks
p.big <p> elements that have the class big
article > p <p> elements directly inside an <article>
article p <p> elements anywhere inside an <article> 
p.big       { font-size: 20px; }
article > p { color: blue; }

Pseudo-classes

A pseudo-class picks an element in a certain state or position: selector:pseudo-class.

a:link, a:visited { color: teal; }     /* links, before and after visiting */
a:hover           { color: orange; }   /* pointer over it */
a:active          { color: red; }      /* while being clicked */

header li:nth-child(3)     { font-weight: bold; }  /* the 3rd item */
section div:nth-child(odd) { background: #eee; }   /* 1st, 3rd, 5th... */
section div:nth-child(4):hover { color: red; }      /* can be combined */

Where to put CSS

Keep CSS in its own file and link it in <head>:

<link rel="stylesheet" href="style.css">

One file can style every page, and the browser caches it.

The cascade: which rule wins

When several rules style the same element, the browser decides in this order:

  1. Specificity: the more specific selector wins.
  2. Order: on a tie, the rule written last wins.
  3. Inheritance: some properties (color, font) pass from parent to child when nothing else sets them.

Rules that don't clash all apply together.

Styling text

body {
  font-family: "Open Sans", Arial, sans-serif;  /* fallbacks, then a generic family */
  font-size: 16px;            /* the browser default */
  font-weight: bold;
  font-style: italic;
  text-transform: uppercase;
  text-align: center;
  text-decoration: underline;
  line-height: 1.6;           /* line spacing */
  letter-spacing: 0.05em;
  word-spacing: 0.2em;
  color: #0000ff;
}

Relative sizes grow with the reader's settings:

Unit Relative to Example
% The parent's font size 120% of 16px = 19.2px
em The parent's font size 2em = twice the parent's size
rem The root (<html>) font size 1.5rem = 24px, everywhere

The box model

* { box-sizing: border-box; }   /* put this at the top of every stylesheet */

.card {
  width: 300px;                 /* includes padding and border, thanks to border-box */
  padding: 10px;                /* all four sides */
  border: 3px solid black;      /* width, style, colour */
  margin: 40px 20px;            /* top/bottom 40px, left/right 20px */
  overflow: auto;               /* scroll bar if the content doesn't fit */
}
  • Four values go clockwise from the top: padding: 10px 20px 10px 20px is top, right, bottom, left.
  • Vertical margins collapse: between two stacked boxes, only the bigger margin is used. Side-by-side margins add up.
  • Browsers give <body> an 8px margin. Reset it with body { margin: 0; }.

Styling lists

.menu {
  list-style: none;          /* remove the bullets */
  padding: 0;
}
.menu li { display: inline; }             /* items side by side */
.fancy   { list-style: square; }          /* change the bullet */
.custom li { list-style-image: url("star.png"); }   /* your own bullet */

Backgrounds

.hero {
  background-color: blue;
  background-image: url("sky.jpg");
  background-repeat: no-repeat;
  background-position: top right;
  background-size: cover;      /* fill the box */
}

.hero { background: url("sky.jpg") no-repeat top right / cover; }   /* the same, in one line */

Floats

float pushes an element to the left or right and lets text wrap around it, like a photo in a newspaper.

img.side { float: right; }
.footer  { clear: both; }    /* start below any floats */
  • A floated element leaves the normal flow.
  • clear: left | right | both moves an element below earlier floats.

For page layout, use flexbox or grid instead. Floats are now mainly for wrapping text around images.

Relative and absolute positioning

position Moves relative to Keeps its space in the page?
static (default) Doesn't move Yes
relative Where it would normally be Yes
absolute The nearest positioned ancestor (or the page) No
fixed The browser window No
sticky Normal, until it reaches the given offset when scrolling Yes 
.card  { position: relative; }   /* becomes the reference point */
.badge { position: absolute; top: 10px; right: 10px; }   /* corner of .card */

Fixed elements

A fixed element stays in the same place on screen while the page scrolls: good for headers and "back to top" buttons.

.back-to-top {
  position: fixed;
  bottom: 20px;
  right: 20px;
}

Media queries

Change the styles depending on screen size.

p { color: black; }                         /* base styles for every screen */

@media (max-width: 600px) {                 /* phones */
  p { color: blue; }
}
@media (min-width: 900px) and (max-width: 991px) { ... }   /* and: both must be true */
@media (max-width: 900px), (min-width: 1220px) { ... }     /* comma: either one */
  • Write base styles first, then override them for particular sizes.
  • Don't let ranges overlap: end one at 991px and start the next at 992px.

CSS grid

Grid lays things out in rows and columns at the same time (flexbox does one direction).

.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);   /* 3 equal columns; fr = a share of the free space */
  grid-auto-rows: minmax(100px, auto);     /* rows at least 100px, taller if needed */
  gap: 1em;                                /* space between rows and columns */
}
.wide { grid-column: 1 / 3; }   /* from line 1 to line 3: two columns */
.tall { grid-row: 1 / 3; }      /* two rows */
Property On Does
justify-items the grid Places every item inside its cell, horizontally
align-items the grid ...vertically
justify-self, align-self one item The same, for one item

Values: start, center, end, stretch.

Flexbox

Flexbox lines items up in one direction and shares out the space between them.

.row {
  display: flex;
  flex-direction: row;              /* or column */
  flex-wrap: wrap;                  /* move items to a new line when there's no room */
  justify-content: space-between;   /* along the main axis */
  align-items: center;              /* along the cross axis */
  gap: 1rem;
}
.row .grow { flex: 1; }             /* take the space that's left */
On the container Values
justify-content flex-start center flex-end space-between space-around space-evenly
align-items flex-start center flex-end stretch
flex-wrap nowrap wrap wrap-reverse
On an item Does
flex-grow How much of the extra space it takes
flex-shrink How much it gives up when space is short
flex-basis Its starting size (like width)
flex: 1 Shorthand for all three
align-self Its own cross-axis alignment
order Its position, without changing the HTML

Wireframes

Navigation bar

Bootstrap's navbar component is a good starting point: copy the example and change it to fit. It already collapses into a menu button on phones.

Bootstrap grid

<div class="container">              <!-- centres the content and adds side padding -->
  <div class="row">                  <!-- a row of columns -->
    <div class="col-md-8">Main</div>
    <div class="col-md-4">Sidebar</div>
  </div>
</div>

col-{size}-{span}: the columns sit side by side from that screen size up, and stack below it.

Class Side by side from
col- always
col-sm- 576px
col-md- 768px
col-lg- 992px
col-xl- 1200px

Classes can be combined: col-12 col-md-6 col-lg-4 is full width on phones, half on tablets and a third on laptops.
