Astrobee Robot Software

2021 to 2022

Control and navigation software for NASA's Astrobee free-flying robot, run aboard the International Space Station in JAXA's Kibo module for the KIBO Robot Programming Challenge. Real-time pose estimation from QR and AR tags guides the robot, tested in ROS and RViz before flight. Runner-up in 2021 and Crew Award winner in 2021 and 2022.

  • Java
  • OpenCV-Contrib
  • ROS
  • RViz

Clear Frame

2023

Batch image cleaner for e-commerce product photos, built for the graphics team at Daraz. Detects people with MobileNetV3, cuts out the subject with U-2-Net, then cleans, heals or replaces the background without touching subject detail.

  • Python
  • OpenCV
  • Tkinter
